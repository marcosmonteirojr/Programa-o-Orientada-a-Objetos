## 🎯 Objetivos de Aprendizagem

Ao final desta unidade, o estudante será capaz de:

- **Compreender a história e os objetivos fundamentais da linguagem Java**, incluindo o princípio de portabilidade *"Write Once, Run Anywhere"* (WORA).
- **Entender o funcionamento da Máquina Virtual Java (JVM)**, do compilador **JIT** *(Just-In-Time)* e da tecnologia **HotSpot** na otimização e execução do código-fonte.
