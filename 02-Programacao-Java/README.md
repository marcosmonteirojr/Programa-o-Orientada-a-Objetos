## 🎯 Objetivos de Aprendizagem

Ao final desta unidade, o estudante será capaz de:

- **Dominar a entrada e saída de dados no console**, utilizando a classe `Scanner` para leitura de dados e os comandos `System.out` para exibição.
- **Identificar e aplicar os tipos primitivos de dados** e dominar as operações de *casting* (conversão de tipos implícita e explícita).
- **Utilizar estruturas de controle de fluxo**:
  - Tomada de decisão: `if-else` e `switch`
  - Laços de repetição: `for`, `while` e `for-each`
- **Declarar, instanciar e manipular vetores** (*arrays*) unidimensionais na linguagem Java.

---

## 🧭 Orientações Gerais

Para um aproveitamento do conteúdo desta unidade, é fundamental seguir o roteiro de estudos recomendado:

1. **Prática Contínua:** Execute todos os códigos demonstrados em aula na sua própria IDE para fixar a sintaxe e identificar possíveis erros em tempo real.
2. **Atividades:** As atividades propostas no AVA são indispensáveis para a consolidação dos conceitos estudados. Realize-as com dedicação.
3. **Engajamento:** A participação ativa e a prática autônoma são essenciais para o seu avanço na programação. Bons estudos!
